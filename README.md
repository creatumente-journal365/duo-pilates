# Duo Pilates Studio — website

One-page website for **Duo Pilates Studio**, a boutique Pilates Reformer studio in Quito
(Monteserrín · Corvo Plaza). Every booking is closed over WhatsApp — no login, no online
payments, no backend.

Live: https://a33bc727c580d488a6c5a729cd455f22.ctonew.app

## What's on the page

Eight sections, mobile-first (designed and verified at 390×844):

1. Fixed navbar
2. Hero — "WANNA FIND YOUR DUO?"
3. "This is Duo" — the three brand pillars
4. "Find your match" — the five packages as sticker cards
5. Schedule — AM / PM / Weekend tabs
6. Location — Corvo Plaza map embed
7. Closing CTA — "Better together"
8. Footer

## Bookings (the only integration)

All 13 buttons are generated from two constants at the top of `src/routes/index.tsx`:

```ts
const WHATSAPP_NUMBER = "593993714411";
const WHATSAPP_DISPLAY = "+593 99 371 4411";
```

Each button opens `wa.me/<number>` with its own pre-filled message (general booking, or
the specific package: KEEP IT CASUAL, DUO FLOW, OBSESSED, BESTIE STATUS, JUST YOU & ME).
To change the number or any message, edit those constants and redeploy.

the logo image. Logos are cut with transparency from the manual's PNGs by
`scripts/brand-logos.mjs`.

## Running it

```bash
bun install
bun run dev        # http://localhost:3000
bun run build
bun run optimize:images   # regenerate the WebP variants + og.jpg
```

Stack: TanStack Start (React + Vite + Tailwind CSS v4), TypeScript, `sharp` for images.

## Images

Heavy originals live in `src/assets/raw/` (never imported, never bundled). The WebP
variants the page actually uses, plus `public/og.jpg` (1200×630 share preview), are
generated by `bun run optimize:images`, which fails if any file exceeds its size budget.
To swap in real studio photos, drop them into `src/assets/raw/` under the same names and
re-run the script.

## Notes

- The page ships with placeholder stock imagery until the studio supplies its own photos.
- No analytics, cookies or tracking are loaded.
